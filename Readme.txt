This Application is a Granny 1.0 (*.grn) Viewer for Ultima Online 3D Character/Monster/Clothes Models.

Grannyviewer also allows to load SMD Files


To run Grannyviewer:

Edit the xml/config.xml and setup the Ultima Online path !


0.4.0.1:-You can register any grn Model or Clothes to view how they wear their clothes.
	-You can select any hue color to every grn Model
	-Import of SMD works (only with one texture for now)
	-lots of other things added

0.2.2: Zoom Buttons added ... to zoom out Models that aren't displayed with the right value.
